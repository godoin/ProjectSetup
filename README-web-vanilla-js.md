# Vanilla JS Setup

## Objective

This repository provides a simple vanilla JavaScript setup with pre-configured components and boilerplate code to help you quickly start frontend development without any build tools like Webpack or Vite. Pure HTML, CSS, and JS.

## Features

- **Frontend Scaffolding**
  - Common UI Components
  - API Helpers
  - Authentication
  - Authentication Error Handling
  - API Endpoints

## Requirements

- Windows >= 8.1 (or any OS that supports a modern browser)
- Modern Web Browser (Chrome, Firefox, Edge, Safari)

## Installation

1. Open your terminal.
2. Clone the repository:
```bash
git clone https://github.com/godoin/ProjectSetup.git
```
3. Open index.html in your browser to start development.

## Usage
- Modify HTML, CSS, and JS files directly.
- No build step required – changes are reflected immediately in the browser.
